# 🎯 Django Quiz App (Вікторина)

Інтерактивний веб-застосунок для проходження тестів та вікторин, написаний на Python з використанням фреймворку Django.

## 🚀 Функціонал
* **Категорії тестів:** Вибір тематичних вікторин.
* **Таймер зворотного відліку:** Автоматичне відправлення результатів після закінчення часу.
* **Історія результатів:** Збереження спроб користувача із зазначенням балів та дати.
* **Адмін-панель:** Зручне додавання питань та варіантів відповідей через `Inline` форми.

## 🛠 Технологічний стек
* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Database:** SQLite
